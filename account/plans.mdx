Open **Manage Plan** to see the current plan, renewal date, and what is included. New accounts start on a trial. When a trial or paid plan expires, sending and API access stop until you choose a plan again.

## Plans

| | Starter | Standard | Premium |
| --- | --- | --- | --- |
| Messages each month | 10,000 | 50,000 | 150,000 |
| Contacts, labels, attributes, broadcasts, templates | Yes | Yes | Yes |
| Developer API, Google Sheets, MCP server | Yes | Yes | Yes |
| WhatsApp ads, drip campaigns, AI bot, catalogs | | Yes | Yes |
| Automations | | 5 | Unlimited |
| WhatsApp Flows | | 5 | Unlimited |
| Team seats | | 5 | 15 |

Starter, Standard, and Premium all include the connected WhatsApp number features listed on **Manage Plan**. Message allowances reset on the billing cycle. Add-ons, when they are offered on the plan page, raise messages, seats, or phone numbers without changing the rest of the plan.

Header image generation for templates has its own monthly cap: 15 on Starter, 50 on Standard, and 100 on Premium. Trial accounts get 2 images for the whole trial.

## If the plan expires

Expired plans block sends, the Developer API, and outbound webhooks. Google Sheets rules turn off and keep the saved API key. Renew the plan, then turn those rules active again.

Team invites and premium features such as automations show an upgrade prompt when the current plan does not include them.

<Info>
  Billing is completed in the dashboard. GreenTick does not ask you to send card details by email.
</Info>
