An automation is a workflow on one WhatsApp number. It starts from a trigger, then sends a reply, a template, a Flow, or a catalog, and can label the contact, update an attribute, or assign the chat.

Open **Automations**. Standard includes 5 automations. Premium includes unlimited automations and a setup session for advanced workflows. Starter does not include the automation builder.

<Info>
  **What are Automations?**

  Automations in GreenTick let you trigger actions based on keywords, time delays, or conversation events. Use them for welcome messages, FAQ auto-replies, drip sequences, and routing chats to the right team member.
</Info>

## Create an automation

<Steps>
  <Step title="Open the Automation section">
    From your GreenTick dashboard, navigate to **Automation** in the left sidebar. You will see a list of your existing automation rules (empty on first use).
  </Step>
  <Step title="Create a new rule">
    Click **\+ Create Automation**. Each rule has three parts: a Trigger, optional Conditions, and one or more Actions.
  </Step>
  <Step title="Set the Trigger">
    Choose when this rule fires. Common triggers: **Keyword received** (customer sends a specific word), **New conversation started**, **No reply in X hours**, or **Contact tag added**.
  </Step>
  <Step title="Add conditions (optional)">
    Narrow when the rule fires. Examples: only trigger if the contact has tag "Lead", or only between 9 AM and 6 PM. Conditions let you build smart, context-aware rules.
  </Step>
  <Step title="Choose your Action(s)">
    Actions execute when conditions are met. Available actions:

    | Action | What it does |
    | --- | --- |
    | Send Message | Auto-reply with a text or template message |
    | Assign Conversation | Route chat to a specific agent or team |
    | Add Tag | Tag the contact automatically |
    | Add to Sequence | Enroll contact in a drip campaign |
    | Close Conversation | Mark chat resolved after auto-reply |
  </Step>
  <Step title="Save and activate">
    Toggle the rule to **Active** and click **Save**. The automation runs instantly for all matching conversations going forward.
  </Step>
</Steps>

## Triggers

| Trigger | When it runs |
| --- | --- |
| Message received | A customer messages this number |
| Webhook event | Your system calls the automation's webhook URL |
| Enroll contacts | A drip campaign enrolls a contact into this workflow |

The first step must be the trigger. Conditions can check the message, a button reply, a label, an attribute, or a click-to-WhatsApp referral before the next step runs.

## Publish

Saving a draft does not run it. **Publish** the automation and turn it on. A webhook trigger shows a secret URL after publish. Treat that URL as a credential. Anyone who has it can start the workflow.

[Drip campaigns](/messaging/broadcasts#drip-campaigns) only list workflows whose trigger is **Enroll contacts**. Publish and turn the workflow on before you select it on the campaign.

## What a step can do

- Send text, media, buttons, a template, a published Flow, or a catalog message
- Add or remove a label, or set an attribute
- Assign the conversation to a [teammate](/account/team) or the [AI bot](/automation/ai-bot)
- Wait, then continue

<Info>
  The API can list enrollable automations and start one with `POST /v1/automations/{id}/enroll`. Webhook triggers use `POST /v1/hooks/{secret}`. Both are in the API reference.
</Info>

<Tip>
  **Keyword matching tip**

  Use common misspellings as separate keyword triggers (e.g., "price", "prise", "pricing"). WhatsApp customers rarely spell perfectly.
</Tip>
