The dashboard at [dashboard.greentick.ai](https://dashboard.greentick.ai) is organized by section in the left sidebar. Most sections work on the phone number you have selected, so check the selected number before you send or change anything.

## Sections at a glance

| Section | What it does | Guide |
| --- | --- | --- |
| **WhatsApp Connections** | Link the WhatsApp Business account and its phone numbers | [Connect WhatsApp](/connect-whatsapp) |
| **Contacts** | Add, import, and export customers, with labels and attributes | [Contacts](/contacts/overview) |
| **Templates** | Create templates and track Meta approval | [Templates](/messaging/templates) |
| **Broadcasts** | Send an approved template to selected contacts now or later | [Broadcasts](/messaging/broadcasts) |
| **Live Chat** | Read and reply to customer conversations as a team | [Live Chat](/messaging/live-chat) |
| **Automations** | Reply, label, and assign chats from a workflow | [Automations](/automation/automations) |
| **Flows** | Build forms that open inside WhatsApp | [WhatsApp Flows](/automation/flows) |
| **AI Bot** | Answer customers from the knowledge you add | [AI Bot](/automation/ai-bot) |
| **Catalogs** | Show products and receive orders in chat | [Catalogs](/automation/catalogs) |
| **WhatsApp Ads (CTWA)** | Handle click-to-WhatsApp ad chats and send conversions | [WhatsApp ads](/automation/whatsapp-ads) |
| **Integrations** | Send from Google Sheets and see upcoming tools | [Google Sheets](/integrations/google-sheets) |
| **Manage Team** | Invite teammates to a number and set their role | [Team](/account/team) |
| **Manage Plan** | See the plan, renewal date, and limits | [Plans](/account/plans) |
| **Developer** | Create API keys and outbound webhooks | [Developer overview](/developers/overview) |

## The selected phone number

**Contacts**, **Templates**, **Broadcasts**, **Live Chat**, and **Developer** all use the phone number selected in the dashboard. Labels, attributes, automations, and Flows also belong to that number. Switch the number before you work on a different line.
