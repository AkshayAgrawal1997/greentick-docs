GreenTick is the dashboard and API for a WhatsApp Business account. You connect the number through Meta, then use that number for contacts, templates, broadcasts, and live chat.

## What you can do

| Area | Where | What it is for |
| --- | --- | --- |
| WhatsApp Connections | Dashboard | Link the business account and its phone numbers |
| Contacts | Dashboard | Store customers, labels, and custom attributes |
| Templates | Dashboard | Submit WhatsApp templates to Meta for approval |
| Broadcasts | Dashboard | Send an approved template to selected contacts |
| Live Chat | Dashboard | Read and reply to customer conversations |
| Automations | Dashboard | Reply, label, and assign chats from a workflow |
| Developer | Dashboard | Create API keys and outbound webhooks |
| Integrations | Dashboard | Send from Google Sheets today; more tools are listed as coming soon |

Open the dashboard at [dashboard.greentick.ai](https://dashboard.greentick.ai). The public API base URL is `https://api.greentick.ai/v1`.

<Note>
  WhatsApp only allows a free-form text reply inside the customer service window, which is 24 hours after the customer's last message. To start a conversation, or to message again after that window closes, send an approved template.
</Note>
