The Click to Chat widget adds a floating WhatsApp button to your website. A visitor clicks it, WhatsApp opens a chat to your number with a pre-filled message, and your team replies in **Live Chat**.

<Info>
  **How it works**

  GreenTick generates a small JavaScript snippet. Paste it into your website's `<body>` tag. A floating WhatsApp button appears on every page, and clicking it opens a pre-filled WhatsApp chat to your number.
</Info>

The widget builder is also available at [dashboard.greentick.ai/click-to-chat](https://dashboard.greentick.ai/click-to-chat).

## Set up the widget

<Steps>
  <Step title="Open the Widget Builder">
    In your GreenTick dashboard, go to **Settings → Click to Chat Widget**. The builder opens with a live preview on the right.
  </Step>
  <Step title="Customize your widget">
    Set your button color, position (bottom-left or bottom-right), pre-filled message (e.g., "Hi! I have a question about your product"), and the WhatsApp number it opens. Enable or disable the greeting bubble that appears above the button.
  </Step>
  <Step title="Copy the code snippet">
    Click **Generate Code**. Copy the generated `<script>` tag.
  </Step>
  <Step title="Paste into your website">
    Paste the snippet just before the closing `</body>` tag on every page, or use your CMS's Custom Code / Footer Script section. See [where to paste the snippet](#where-to-paste-the-snippet).
  </Step>
  <Step title="Verify the widget appears">
    Open your website in a browser and look for the green WhatsApp floating button. Click it to confirm it opens a WhatsApp chat to your GreenTick number with the correct pre-filled message.
  </Step>
</Steps>

## Where to paste the snippet

| Platform | Where to paste |
| --- | --- |
| WordPress | **Appearance → Theme Editor → footer.php**, or a plugin such as Insert Headers and Footers |
| Shopify | **Online Store → Themes → Edit Code → theme.liquid**, before `</body>` |
| Wix | **Settings → Custom Code → Body (end)** |
| Webflow | **Project Settings → Custom Code → Footer Code** |
| Any other site | Before the closing `</body>` tag |

The widget works on any site that lets you add a script, including Squarespace, WooCommerce, BigCommerce, Framer, and plain HTML sites.

## How the button opens

The widget builds a WhatsApp link to your number. On a phone, it opens the WhatsApp app. On a desktop, it opens WhatsApp Web. Chats arrive in **Live Chat** like any other incoming message.

<Tip>
  **Set a pre-filled message per page**

  Use different widget codes on different pages, e.g., product pages can pre-fill "I want to know more about [product name]" and the pricing page can pre-fill "I'd like a quote." This gives your agents instant context.
</Tip>
