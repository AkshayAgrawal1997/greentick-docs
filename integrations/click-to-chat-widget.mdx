The Click to Chat widget adds a floating WhatsApp button to your website. A visitor clicks it, WhatsApp opens a chat to your number with a pre-filled message, and your team replies in **Live Chat**.

GreenTick generates a short `<script>` snippet. Paste it into your site once and the button shows on every page that loads it.

## Set up the widget

<Steps>
  <Step title="Open the widget builder">
    In the dashboard, open **Settings → Click to Chat Widget**, or go to [dashboard.greentick.ai/click-to-chat](https://dashboard.greentick.ai/click-to-chat). The builder shows a live preview on the right.
  </Step>
  <Step title="Customize the button">
    Set the WhatsApp number the button opens and the pre-filled message, for example "Hi! I have a question about your product". Choose the button color, size, and position (bottom-left or bottom-right). Turn the greeting bubble above the button on or off, and add a tooltip or text label such as "Chat on WhatsApp" if you want one.
  </Step>
  <Step title="Copy the code snippet">
    Click **Generate Code** and copy the `<script>` tag.
  </Step>
  <Step title="Paste it into your website">
    Paste the snippet just before the closing `</body>` tag on every page, or in your site builder's custom code or footer script section. See [where to paste the snippet](#where-to-paste-the-snippet).
  </Step>
  <Step title="Check the widget">
    Open your website and look for the green WhatsApp button. Click it and confirm it opens a chat to your GreenTick number with the right pre-filled message.
  </Step>
</Steps>

## Where to paste the snippet

| Platform | Where to paste |
| --- | --- |
| WordPress | **Appearance → Theme Editor → footer.php**, or a plugin such as Insert Headers and Footers |
| Shopify | **Online Store → Themes → Edit Code → theme.liquid**, before `</body>` |
| Wix | **Settings → Custom Code → Body (end)** |
| Webflow | **Project Settings → Custom Code → Footer Code** |
| Any other site | Before the closing `</body>` tag |

The widget works on any site that lets you add a script, including Squarespace, WooCommerce, BigCommerce, Framer, and plain HTML sites.

## How the button opens

The widget builds a WhatsApp link to your number. On a phone, it opens the WhatsApp app. On a desktop, it opens WhatsApp Web. Chats arrive in **Live Chat** like any other incoming message.

<Tip>
  Use a different snippet on different pages so each chat starts with context. A product page can pre-fill "I want to know more about [product name]" and the pricing page can pre-fill "I'd like a quote."
</Tip>
