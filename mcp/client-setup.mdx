Add `https://api.greentick.ai/mcp` as a remote MCP server. The client opens a GreenTick sign-in. Sign in as the account owner and choose the default WhatsApp Business account. One connection covers every WhatsApp Business account that owner owns.

<Warning>
  Do not paste a `gt_live_` Developer API key into the MCP client. That key is rejected on this server. It still works for the Developer API and for Sheets, n8n, and Zapier.
</Warning>

<Warning>
  Connect `https://api.greentick.ai/mcp`. The `/mcp` address on this docs site only searches the documentation. It cannot send WhatsApp messages.
</Warning>

## Claude

In Claude, add the GreenTick connector from the directory, or add a custom connector with the server URL `https://api.greentick.ai/mcp` and choose sign-in. Claude opens the GreenTick consent screen. After you allow it, the connector is ready.

Install the GreenTick plugin as well when you want the workflows for templates, broadcasts, contacts, and the other jobs. The plugin points at the same server. Someone who has both sees one set of tools.

## Claude Code

From a terminal:

```bash
claude mcp add --transport http greentick https://api.greentick.ai/mcp
```

Start a new session. Claude Code opens a browser sign-in on localhost. Finish it as the account owner.

## Cursor

Open **Settings → MCP** and add a remote server:

```json
{
  "mcpServers": {
    "greentick": {
      "url": "https://api.greentick.ai/mcp"
    }
  }
}
```

Do not set an `Authorization` header. Cursor starts the GreenTick sign-in when it connects.

## VS Code

Create `.vscode/mcp.json`:

```json
{
  "servers": {
    "greentick": {
      "type": "http",
      "url": "https://api.greentick.ai/mcp"
    }
  }
}
```

Sign in when VS Code asks. Do not put an API key in this file.

## Which account a tool uses

After sign-in, the assistant calls `list_wabas`.

- If you name a WhatsApp Business account, it passes that `waba_id`.
- If you do not, it uses the default you chose on the consent screen.
- If the request could match more than one account and the default is not the one you mean, it asks.
- A read can pass `waba_id` as `all` to cover every account you own. A send, publish, schedule, enroll, delete, or other change must name one account.
- The consent screen does not ask for a phone line. The first time a change needs a line and the account has more than one, the assistant asks which line and saves it with `set_default_phone`.

Change the default account later by asking the assistant to call `set_default_waba`.

## Confirm the connection

Ask the assistant to list your WhatsApp Business accounts and not to send anything. A working sign-in returns the accounts you own and the saved default.
