These are jobs you can describe in plain language. You do not write the tool calls. The assistant calls them, stops when a tool returns an error, and does not send, publish, schedule, enroll, or enable anything until you ask.

Each use case below is its own page, with its own URL, so you can open the one that matches the job.

| Use case | What you ask for |
| --- | --- |
| [Reply in an open chat](/mcp/use-cases/reply-in-open-chat) | Answer the customer's last message with session text |
| [Send an approved template](/mcp/use-cases/send-approved-template) | Send a template that is already `APPROVED` |
| [Schedule a template](/mcp/use-cases/schedule-template) | Send that template at a later time |
| [Cancel a scheduled message](/mcp/use-cases/cancel-scheduled-message) | Stop a template that has not gone out |
| [Schedule a broadcast](/mcp/use-cases/schedule-broadcast) | Preview the recipient count, then schedule one template to many contacts |
| [Submit a template](/mcp/use-cases/submit-template) | Validate a template and submit it to Meta |
| [Generate a template header](/mcp/use-cases/generate-template-header) | Build a template and a header image from your website |
| [Send an image or PDF](/mcp/use-cases/send-media-in-chat) | Upload a file you already have and send it in an open chat |
| [Import contacts](/mcp/use-cases/import-contacts) | Create contacts, labels, and attributes |
| [Publish a workflow](/mcp/use-cases/publish-workflow) | Copy a starter workflow and publish the draft |
| [Enroll an automation](/mcp/use-cases/enroll-automation) | Add contacts to a workflow that is already published |
| [Send a WhatsApp Flow](/mcp/use-cases/send-whatsapp-flow) | Publish a Flow, send it, and read submissions |
| [Assign a live chat](/mcp/use-cases/assign-live-chat) | Hand a Live Chat thread to a teammate |
| [Suggest a reply](/mcp/use-cases/suggest-reply) | Draft a reply and leave it unsent |
| [Send a catalog product](/mcp/use-cases/send-catalog-product) | Share one product, or the catalog, inside an open chat |
| [Add a catalog product](/mcp/use-cases/add-catalog-product) | Create a product from an image you already have |
| [Enable an AI bot](/mcp/use-cases/enable-ai-bot) | Add knowledge, run a test, then enable the bot |
| [Send an ad conversion](/mcp/use-cases/send-ad-conversion) | Report a qualified lead or purchase from a click-to-WhatsApp ad |
| [Check plan usage](/mcp/use-cases/check-plan-usage) | Read limits and usage before a write |

Tool arguments and error codes stay on the [tool pages](/mcp/messages). Stop conditions stay on [Rules](/mcp/rules).
