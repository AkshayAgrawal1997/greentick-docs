The GreenTick MCP server lets an assistant use your WhatsApp Business account. It calls the Developer API with your API key. The server address is `https://api.greentick.ai/mcp`.

GreenTick sends the assistant a fixed set of instructions. Those rules are written out in [Rules](/mcp/rules). Tool arguments and stop conditions are on the pages linked below.

The server is included on Starter, Standard, and Premium. An expired plan rejects every tool call with `PLAN_EXPIRED`.

## Connect a client

<Steps>
  <Step title="Create an API key">
    Open **Developer**, enter a **Key name**, and click **Create API key**. Copy the `gt_live_…` secret. It is shown once. The key belongs to the WhatsApp Business account you had selected.
  </Step>
  <Step title="Add the server">
    Use streamable HTTP. Send the key as `Authorization: Bearer gt_live_…` on every request. A bare key, without the `Bearer` prefix, is rejected.

    <CodeGroup>

    ```json Cursor
    {
      "mcpServers": {
        "greentick": {
          "url": "https://api.greentick.ai/mcp",
          "headers": {
            "Authorization": "Bearer gt_live_YOUR_API_KEY"
          }
        }
      }
    }
    ```

    ```json Claude
    {
      "mcpServers": {
        "greentick": {
          "type": "http",
          "url": "https://api.greentick.ai/mcp",
          "headers": {
            "Authorization": "Bearer gt_live_YOUR_API_KEY"
          }
        }
      }
    }
    ```

    </CodeGroup>
  </Step>
  <Step title="Confirm the connection">
    Ask the assistant to call `get_api_key`. A working key returns the key name, the key prefix, and the account `timeZone`. An empty timezone means the account timezone is not set yet. The assistant uses that timezone when you schedule a template without naming a zone.
  </Step>
</Steps>

<Warning>
  The API key can send messages and change templates, workflows, and contacts for the whole WhatsApp Business account. Keep it in the client header. Do not paste it into a chat, a screenshot, or a committed file.
</Warning>

A `GET` to `https://api.greentick.ai/mcp` without a key only reports that a server named `greentick` exists and that the probe itself does not require sign-in. Listing and calling tools still needs the Bearer key.

The **Integrations** card in the dashboard can still say the MCP server is coming soon. Connect the URL above yourself. You do not wait for that card.
