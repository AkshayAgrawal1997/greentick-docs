`assign_conversation` changes who owns a Live Chat thread. It does not send a WhatsApp message. Use it when you want the assistant to file the chat, not to reply.

## Ask this

```text
Find the open conversation with +14155550123. Assign it to the teammate named Priya and mark the thread read. Do not send a reply.
```

## What the assistant calls

<Steps>
  <Step title="Find the thread">
    `list_conversations` lists threads. `phoneNumberRef`, `cursor`, and `limit` are in the schema. `phoneNumberRef` is optional when the account has one number. `list_conversation_messages` can show the latest messages before you decide who should own it. `before` and `limit` page that thread.
  </Step>
  <Step title="Choose who owns it">
    `list_teammates` returns people. Pass `teammates[].id` when `assigneeType` is `user`. The owner id is an email. A member id is that person's user id. `list_teams` returns teams. Pass `teams[].id` when `assigneeType` is `team`. For a bot, use an id from `list_ai_bots`. `assigneeType` is `unassigned`, `user`, `bot`, or `team`.
  </Step>
  <Step title="Assign and mark read">
    `assign_conversation` takes `assigneeType` and `assigneeId`. An invalid type returns `unassigned`, `user`, `bot`, and `team`. Person and team ids are on [Team](/mcp/team). `mark_conversation_read` marks the thread read. For one inbound message, `mark_message_read` is on [Messages](/mcp/messages).
  </Step>
</Steps>

A suggested reply that stays unsent is [Suggest a reply](/mcp/use-cases/suggest-reply). Sending text is [Reply in an open chat](/mcp/use-cases/reply-in-open-chat). Inbox tools are on [Inbox](/mcp/inbox).
