`get_plan`, `get_usage`, `get_billing_info`, and `list_invoices` are reads. They do not buy, change, pause, cancel, or pay. Call them before a large broadcast, a new Flow, or a template, so the assistant can tell you when a field or a feature will be rejected.

## Ask this

```text
Check my plan, usage, and latest invoices. Do not send, publish, create, or change the plan. If the plan is expired, say so and stop.
```

## What the assistant calls

<Steps>
  <Step title="Read the plan">
    `get_plan` returns the plan name, status, renewal date, and included messages, AI tokens, automations, Flows, bots, seats, and phone numbers, with how many are used. `get_usage` returns message and AI token usage. `get_billing_info` reads the billing name and address. `list_invoices` lists invoices. `get_limits` returns the field limits the assistant must respect before it writes template, workflow, Flow, bot, catalog, or message text.
  </Step>
  <Step title="Stop on plan errors">
    `PLAN_EXPIRED` means the plan is expired. `FEATURE_NOT_INCLUDED` means this plan does not include that tool. The assistant does not retry `PLAN_EXPIRED` until you renew on **Manage Plan**. It does not buy or change the plan from a tool.
  </Step>
</Steps>

Write calls are also capped at 60 a minute per API key. That limit, and the error codes, are on [Rules](/mcp/rules).
