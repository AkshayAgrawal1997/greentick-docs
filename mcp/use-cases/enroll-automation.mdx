`enroll_automation` adds up to 100 contacts to a published automation that is switched on. Pass `contacts`, each with `to` and `phoneNumberRef`. The assistant does not enroll a draft, and it does not enroll anyone until you ask. A draft says the workflow is a draft. A published workflow that is switched off says it is switched off. `publish_workflow` switches a workflow on. `set_workflow_active` can switch it off or back on.

## Ask this

```text
List published automations. If "Welcome reply" is published, enroll +14155550123 and +14155550124. If it is still a draft, stop and tell me it has to be published first.
```

## What the assistant calls

<Steps>
  <Step title="Read published automations">
    `list_automations` returns published automations that can be enrolled. `list_workflows` shows draft and published status if you need to tell those apart.
  </Step>
  <Step title="Enroll">
    `enroll_automation` takes `contacts`, up to 100 items of `{ to, phoneNumberRef }`. The assistant calls it only after you ask, and only when the automation is published and switched on.
  </Step>
</Steps>

Publishing the draft is a separate step, on [Publish a workflow](/mcp/use-cases/publish-workflow). Tool order is on [Automations](/mcp/automations).
